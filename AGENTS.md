# Repository instructions

For any frontend/UI task, read and obey
[docs/15_UI_DESIGN_SYSTEM.md](docs/15_UI_DESIGN_SYSTEM.md) before implementation.
UI implementation must not override those rules without explicit human approval.
Read the relevant business requirements alongside the design contract.

You may read and edit `.env` and `.env.local` when task-relevant. Keep credentials
private; never print secrets or commit environment files containing them.
